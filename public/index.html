How to Verify EDR Agent is Running on PC

When you double-click shield_installer.bat, Windows opens CMD, installs the service, and closes after you press a key. Closing CMD DOES NOT stop the agent! The agent stays running in the Windows kernel background 24/7.

Method 1: Check Windows Services (`Services.msc`)

1. Press Win + R → Type services.msc → Press Enter.
2. Look for Wazuh or WazuhSvc.
3. Status will read Running and Automatic!

Method 2: Check Real-Time Log File

Open C:\Program Files (x86)\ossec-agent\ossec.log in Notepad.
You will see live connection lines: Connected to server 10.0.11.57:1514.
