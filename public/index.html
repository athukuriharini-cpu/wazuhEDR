📚 Platform Technical Architecture & Documentation

Comprehensive breakdown of ShieldEDR's security architecture, kernel telemetry drivers, and automated containment engines.

1. Multi-Tenant Group Silos

Accounts receive cryptographically isolated tenant group tokens (GRP_<UID>). User A can never view or access User B's devices or security logs.

2. Sysmon Kernel Telemetry

Monitors Windows Kernel events: Event ID 1 (Process Creation), Event ID 3 (Network Sockets), and Event ID 11 (File Creation & Ransomware Tracking).

3. Automated Active Response

When ransomware or malicious shellcode is detected, the EDR active-response daemon terminates malicious PIDs and isolates compromised endpoints in under 500ms.

⚙️ Operational Workflow Guide

Understanding how the EDR agent monitors processes, transmits logs over TLS, and communicates with the central manager.

Agent Execution Architecture

1. Installation: `msiexec` installs binaries to `C:\Program Files (x86)\ossec-agent\`.
2. Background Kernel Service: Registers `WazuhSvc` in Windows Services (`Services.msc`) set to Automatic.
3. Log File Location: Real-time connection events are written to `C:\Program Files (x86)\ossec-agent\ossec.log`.
4. 24/7 Protection: The agent remains running even when no browser or terminal window is open.
