📚 Platform Technical Architecture & Documentation

Multi-Tenant Silo Isolation

Accounts receive cryptographically isolated tenant group tokens (GRP_<UID>). This guarantees absolute data privacy — User A can never view or access User B's devices or security logs.

Sysmon Event Telemetry Engine

Monitors Windows Kernel events in real-time: Event ID 1 (Process Creation & Command Lines), Event ID 3 (Network Sockets), and Event ID 11 (File Creation & Ransomware Tracking).

Automated Active Response Engine

When ransomware or malicious shellcode is detected, the EDR active-response daemon terminates malicious PIDs and isolates compromised endpoints from the local network in under 500ms.
